# Tourism Analysis API

## Описание 
Проект представляет собой веб-API на основе Flask для анализа данных о туризме. Приложение подключается к базе данных PostgreSQL, вычисляет ключевые показатели эффективности (KPI) и предоставляет их через REST API. Проект анализирует данные о туристах, включая демографическое распределение, географическое распределение, популярные направления и профиль среднего туриста.

## Установка и запуск

1. Установите зависимости:
pip install -r requirements.txt

2. Убедитесь, что у вас есть доступ к базе данных PostgreSQL с необходимыми данными. Настройте параметры подключения в файле .env.

3. Запустите приложение:
python app.py

Приложение будет доступно по адресу http://localhost:5000.

## Тестирование API

После запуска приложения вы можете протестировать следующие endpointы:

Проверка работоспособности:
GET http://localhost:5000/health

Получение всех KPI:
GET http://localhost:5000/kpi

Получение KPI за определенный период:
POST http://localhost:5000/kpi
Content-Type: application/json

{
  "start_date": "2023-01-01",
  "end_date": "2023-12-31"
}

## Структура проекта
app.py - основное Flask-приложение с API-эндпоинтами
analysis.py - модуль для вычисления KPI из базы данных
config.py - конфигурационные параметры для подключения к БД
requirements.txt - зависимости проекта
final.csv - данные для анализа
